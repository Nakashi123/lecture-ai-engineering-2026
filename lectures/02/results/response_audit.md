# Day2 実測結果の確認記録（Colab T4）

## 原資料
アップロードされた `day2_basic_both_runs_results.zip` 内の`epochs20/result.json`、`epochs10/result.json`、両条件の`eval_before.json`/`eval_after.json`、`comparison.csv`、`experiment_metadata.json`を照合。両条件はtest 21問、学習前形式正解2問、学習前内容正解0問。学習後は20エポック形式21問・内容19問、10エポック形式21問・内容17問。

## 学習後の不正解一覧（内容判定）

| 条件 | 質問 | 正解の`needs_review` | 実際の`needs_review` | 不正解の理由 |
|---|---|---|---|---|
| 20 | 成績はいつ出ますか | true | false | FAQにないのに、PDF提出形式の説明を流用して断定 |
| 20 | オフィスアワーは事前予約が必要ですか | true | false | 開催曜日・時間から予約の要否を断定 |
| 10 | PDF 以外でも出せますか | false | true | FAQにはPDF1ファイルと記載されているのにFAQ外と判断 |
| 10 | 成績はいつ出ますか | true | true | 回答に指定語句「確認」を含まない |
| 10 | 課題の文字数に制限はありますか | true | true | 回答に指定語句「確認」を含まない |
| 10 | 参考文献の書き方に指定はありますか | true | true | 回答に指定語句「確認」を含まず、FAQにない「参考文献」欄にも言及 |

### 解釈
10エポックで`needs_review`が正しくても、文章に「確認」を含まない場合は配布コードの`content_rate`で不正解となる。したがって`content_rate`は判定フラグ単独の正解率ではない。また、学習前`content_rate`は両条件0/21である一方、`format_rate`は2/21だった。`both_rate`は「形式・内容の両方の正解」であり、今回の学習後は両条件で`content_rate`と同値。

### セクション6の注意
`knowledge`の質問「課題の提出期限はいつですか」はFAQにある対照質問。しかし配布コードが`q in gold`（test質問だけに用意したgold辞書）で「FAQ にある」を算出しているため、出力フラグが`false`になる。FAQ本文を優先して解釈した。架空FAQの「9月30日23:59」は実際の講座締切ではない。

### 実行上の限界
一括実行版は同じColabセッションで学習済みモデルを解放し基盤モデルを再読み込みした。資料指定の`ランタイム → セッションを再起動`とは異なる。GPUの学習ばらつきは検証していない。
